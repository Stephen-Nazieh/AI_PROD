# AP Statistics Movie Series — production runs

Each production run (episode/video) is a subfolder here with the standard pipeline tree:

`01-scripts/  02-storyboards/  03-layout/  04-raw_renders/  05-assets/  06-audio/  07-editing/  08-subtitles/  09-deliver/`

Create a run with:

    python3 01_SKILLS/init_project.py create ap-stats-<run> --title "..."
