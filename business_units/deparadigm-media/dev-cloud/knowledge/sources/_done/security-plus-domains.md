CompTIA Security+ SY0-701 — Exam Domains

1. General Security Concepts (12%): CIA triad, controls (technical/managerial/
operational/physical), zero trust, cryptography basics, PKI.
2. Threats, Vulnerabilities & Mitigations (22%): threat actors, attack surfaces,
social engineering, malware, vulnerability types and mitigations.
3. Security Architecture (18%): secure design, cloud/virtualization, IaC, zero
trust architecture, data protection, resilience.
4. Security Operations (28%): hardening, monitoring, IAM, automation, incident
response, digital forensics, vulnerability management.
5. Security Program Management & Oversight (20%): governance, risk management,
third-party risk, compliance, audits, security awareness.

Study focus: Operations is the heaviest domain — drill IAM, logging/SIEM, and IR.
