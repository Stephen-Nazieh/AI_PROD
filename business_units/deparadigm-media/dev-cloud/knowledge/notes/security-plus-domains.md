# CompTIA Security+ SY0-701 Exam Domains

## 1. General Security Concepts (12%)
- **CIA Triad**: Confidentiality, Integrity, Availability
- **Controls**: Technical, Managerial, Operational, Physical
- **Zero Trust**: Security model that assumes a breach is inevitable and requires constant verification
- **Cryptography Basics**: Encryption, decryption, keys, algorithms
- **PKI (Public Key Infrastructure)**: Certificate Authority, digital certificates, public and private keys

## 2. Threats, Vulnerabilities & Mitigations (22%)
- **Threat Actors**: External, internal, accidental, natural
- **Attack Surfaces**: Network, application, physical, human
- **Social Engineering**: Phishing, pretexting, baiting, quid pro quo
- **Malware**: Viruses, worms, Trojans, ransomware
- **Vulnerability Types and Mitigations**: Common vulnerabilities, patch management, access controls, firewalls

## 3. Security Architecture (18%)
- **Secure Design**: Principles of secure design, threat modeling
- **Cloud/Virtualization**: Security in cloud environments, virtual machine security
- **IaC (Infrastructure as Code)**: Tools like Terraform, Ansible, CloudFormation
- **Zero Trust Architecture**: Implementation of zero trust principles
- **Data Protection**: Data encryption, access controls, data loss prevention
- **Resilience**: Backup and recovery, disaster recovery planning

## 4. Security Operations (28%)
- **Hardening**: Minimizing attack surface, reducing vulnerabilities
- **Monitoring**: Real-time monitoring, log analysis, SIEM (Security Information and Event Management)
- **IAM (Identity and Access Management)**: User authentication, authorization, access controls
- **Automation**: Automating security tasks, incident response
- **Incident Response**: Incident detection, containment, eradication, recovery
- **Digital Forensics**: Investigating cyber incidents, evidence collection
- **Vulnerability Management**: Identifying, assessing, and mitigating vulnerabilities

- **Governance**: Organizational policies, compliance frameworks
- **Risk Management**: Risk assessment, risk mitigation, risk transfer
- **Third-Party Risk**: Assessing risks from vendors and partners
