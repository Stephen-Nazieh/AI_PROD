# Channel Style — Ambient Deep-Focus Loops

**Goal:** Long-form (1–10h) calm focus loops that recede into the background and
keep people in flow.
**Voice/tone:** The "voice" is mood, not narration. Copy (titles/descriptions) is
calm, plain, and keyword-rich — never hypey.
**Audience:** People studying, coding, or relaxing who want unobtrusive ambience.
**Do:** Evoke a single consistent calm scene; keep everything steady and soothing;
write descriptive, searchable titles.
**Don't:** Hooks, surprises, build-ups, exclamation, or anything that pulls
attention from the work.
**Sample title:** "Rainy Night Coding — Deep Focus Lofi — 10 Hours (No Ads)".

## Output paths
Your file writes are auto-filed into this channel's current production run. Save each deliverable to its canonical pipeline stage using a RELATIVE path (e.g. `01-scripts/screenplay.md`) — never an absolute path, never the repo root, and do not include `business_units/…` or a run name (the runtime adds those):
`01-scripts/` (scripts/outlines) · `02-storyboards/` · `03-layout/` · `04-raw_renders/` · `05-assets/` · `06-audio/` (voice/music/dub) · `07-editing/` (FCPXML) · `08-subtitles/` · `09-deliver/` (final + thumbnail).

**For this channel:** Save the base loop to `04-raw_renders/`, audio bed to `06-audio/`, title/metadata to `01-scripts/`, the long-form master to `09-deliver/`.
