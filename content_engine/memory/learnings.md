# Content Engine — Learnings

> Craft lessons that accumulate over time. Each is tagged `[agent]` (or `[general]`) and is
> auto-injected into that agent's prompt, so the system self-improves. Add via
> `memory.add_learning(agent, text)` or just edit this file.

- [scriptwriter] Output PLAIN-TEXT screenplay only — no markdown italics/bold/asterisks around action lines or parentheticals; they break the producer's parser.
- [scriptwriter] Hook in the first 3 seconds on tension, motion, or a surprising claim. Never open with "Hey guys" or throat-clearing.
- [scriptwriter] Keep it within the length target; cut any line that doesn't hook, escalate, turn, or pay off.
- [director] Infer each character's gender + age from their name and dialogue, then cast a matching avatar AND a matching-gender voice. Never give a clearly-male character a female voice.
- [director] Make the two leads visibly distinct (hair/colour/silhouette) so the audience tracks who's who.
- [general] The local 4-bit mlx models repeat/loop without repetition penalties — these are set in llm.py; keep max_tokens modest.
- [general] Set builders must NOT carry show-specific default props (the office/conference/whiteboard sets leaked AP-Stats slide text into a general horror short). Props default to generic/empty; the show bible provides any on-screen text.
- [general] Episode stitch fails (0-byte output) if the title card aspect ratio differs from the scenes — make_title MUST render at the bible resolution (vertical title for social). Fixed in produce.py.
- [director] Give a punchy 2-4 word EPISODE title in the JSON, not the location heading (a social short titled LIGHTHOUSE NIGHT should be e.g. The Last Light).
- [director] For SOCIAL format: title must be a punchy 2-4 word curiosity hook (e.g. The Last Light), NOT the location name. Always emit a hook line. Social opens directly on content — no title card — and the social finisher burns captions + overlays the hook over the first content shot.
- [scriptwriter] SOCIAL is watched sound-off with burned captions: each spoken cue is also a caption, so keep every HOST/character line to one short sentence (<=12 words). First spoken line must stop the scroll (concrete image/bold claim/question, never a preamble). 5-9 punchy lines, end on a landing line.
- [director] HOOK must be drawn from the single most surprising FACT/claim in the script (e.g. Octopuses have THREE hearts), not a generic mood/setting question (What lies beneath?). The concrete shocking fact stops the scroll; atmospheric questions do not.
- [director] Some character VRMs in the catalog do NOT use VRoid J_Bip_* bone names; bl_scene_engine now resolves head/chest bones tolerantly (exact->substring->geometric fallback) so any avatar renders. Casting any catalog avatar is safe.
- [director] Casting variety: narrators/single-host pieces rotate through a gender-consistent PRESENTER_POOL (avatar+voice) keyed by a per-run seed (the run dir name), so a channel batch shows different faces/voices instead of all af_heart. Named multi-character casts still use LLM gender-matched casting.
- [director] Hooks: strip cheesy filler suffixes (— wow!/really?/insane!/mind blown) via clean_hook(); the bare fact IS the hook. Applied in build_bible and rehook.
- [scriptwriter] Social producer adds per-shot punch-in motion (alternating push-in/push-out Ken Burns at the compositing layer of clip_from_frames) for watch-time — independent of the Blender camera push. No re-render needed to change it; it applies on re-stitch.
- [scriptwriter] When looping shell over runs that call ffmpeg/Blender, redirect the inner command stdin from /dev/null AND pass ffmpeg -nostdin. Otherwise ffmpeg/Blender consume the loop stdin and silently skip or mangle later iterations (saw daily-curiosities 02/03 skipped, 04 mangled). The ff() helpers now use -nostdin.
- [scriptwriter] Scriptwriter sometimes emits markdown emphasis (**word**) in dialogue despite instructions; it leaked into burned captions. Captions are now stripped of */_/` markdown both at SRT creation (produce.py) and at burn time (finish.py parse_srt).
- [scriptwriter] Topical B-roll: ffmpeg zoompan/scale yields a non-1:1 SAR (e.g. 10240:10241); concat REQUIRES uniform SAR, so all clips (avatar clip_from_frames + image_clip) must end their filter chain with setsar=1 or concat fails to a 0-byte file. Guard concat output on file SIZE, not just existence.
- [director] engine.step_produce now only accepts an episode whose mtime is newer than the produce start — a produce.py crash can otherwise silently fall back to a STALE prior render and 'pass' QA on old content.
- [director] B-roll image-search terms must anchor on the short's concrete main subject (octopus, Eiffel Tower); abstract terms ('taste buds','eight tongues') return wrong CC stock images. ComfyUI local-gen (running on :8188) is the higher-relevance fallback if stock quality is poor.
- [director] B-roll image quality: CC stock search returns dark digitized BOOK SCANS for abstract/compound queries (saw a black library-barcode page for 'honey's eternal preservation'). Fixes: (1) Openverse category=photograph, (2) reject fetched images that are too dark (luma<45) or near-grayscale (low saturation = document/diagram), trying multiple candidates, (3) director emits SIMPLE 1-2 word photographable nouns ('honey jar','octopus tentacle'), never abstract phrases.
- [director] B-roll relevance SOLVED via ComfyUI local-gen backend (broll_images.generate_comfyui): dreamshaper_8 SD1.5, 512x768, ~9s/image on this Mac, always on-topic + photoreal (banana→real banana, not a periodic table). BACKEND env: 'comfyui' (local only), 'stock' (Openverse/Wikimedia), 'auto' (ComfyUI→stock fallback, default). Free CC stock returns wrong/illustration images for abstract science claims; local-gen fixes it.
- [director] ComfyUI B-roll for ABSTRACT subjects: artistic SD models (dreamshaper) default to a creepy human FACE for terms like 'bacteria'. Fix in _comfy_graph: (1) hard-negative 'person, face, human, portrait, body, skin' always, (2) detect science terms (SCIENCE set: bacteria/cell/microbe/molecule/isotope/...) and frame as 'microscope photography, scientific macro, petri dish'. Turns 'bacteria' into a proper vivid microscopy image.
- [scriptwriter] Autonomous scheduler (scheduler.py, cron daily 10:00) generates content hands-free but does NOT auto-post (queues for review). GOTCHA: the local 4-bit 32B LLM HALLUCINATES 'facts' (invented avocado-art, fake records) — unusable for fact channels ungrounded. Fix: per-channel hand-verified channels/<slug>/idea_seeds.txt takes priority; LLM is overflow only. Keep seed banks stocked for factual channels.
- [reference] Local stack auto-start: launchd agents in ~/Library/LaunchAgents/com.deparadigm.{mlx-smart:8000=32B, mlx-code:8001=Coder7B, mlx-fast:8002=7B, comfyui:8188}.plist (RunAtLoad+KeepAlive). GOTCHA: bootstrap-while-logged-in often won't fire RunAtLoad/KeepAlive (works at real login); use `launchctl kickstart gui/$(id -u)/com.deparadigm.<label>` to start now. Watchdog: content_engine/ensure_stack.sh (cron */10) kickstarts any down service — the reliable safety net.
- [reference] mlx_lm.server /v1/models returns the full CACHED-MODEL CATALOG, not the loaded model — data[0] is misleading (often 7B for all ports). The actually-served model is set by the server's --model flag (verify via `ps -p <pid> -o command=`). Each server only serves its one loaded model regardless of the catalog list.
- [feedback] zsh does NOT word-split unquoted vars (unlike bash): `set -- $spec` keeps it one word. Use explicit function args or ${=var}. Also scripts run via launchd/cron have a minimal PATH — set PATH explicitly so `date`/`curl` resolve.
