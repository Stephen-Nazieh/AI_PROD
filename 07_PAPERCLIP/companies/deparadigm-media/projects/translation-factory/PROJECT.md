# Multi-Language Translation Factory

An automated dubbing pipeline using XTTS v2 voice cloning to produce native-quality 
Spanish and Mandarin audio tracks from English source content.

## Key Deliverables

- XTTS v2 cloned voice tracks (Spanish, Mandarin)
- Synchronized subtitle files (SRT, VTT)
- Quality audit reports per language pair
- Batch processing manifests for 10h/week throughput

## Output Directory

`03_ASSETS/` (audio dubs) → `02_CURRICULUM/compiled_wiki/` (subtitles)
