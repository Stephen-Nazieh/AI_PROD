# DeParadigm Media

A local-first, AI-powered media network building a portfolio of specialized
content brands — each serving a unique audience across video, social, web, and
newsletters — combining human oversight with scalable local-AI production.

## Business Units (Channels)

1. **Dev & Cloud** — Serverless GCP architectures, AWS transitions, Security+ compliance
2. **AP Statistics Movie Series** — Cinematic, story-driven multi-episode seasons
3. **Multi-Language Translation Factory** — Automated Spanish and Mandarin dubbing via XTTS v2
4. **Ambient Deep-Focus Loops** — 10-hour passive coding ambience channels

## Local Infrastructure

- **Inference**: mlx-lm server on `http://127.0.0.1:8000/v1`
- **Orchestration**: Paperclip on `http://127.0.0.1:3100`
- **Bridge**: Python bridge server on `http://127.0.0.1:3101`
- **Database**: Embedded PostgreSQL (Paperclip) + Postgres port 5433 (governance ledger)
- **Docker**: OpenClaw (18789), Open WebUI (3000), Playwright (30005)
