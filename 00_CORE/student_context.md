# Student Context Vault

Historical learning profiles drawn from 6 years of high school mathematics classroom instruction (AP Statistics, Calculus AB, Pre-Calculus Models). These profiles guide creative scripting agents in auto-adjusting tutorial scripts to match individual learner archetypes and preempt known conceptual roadblocks.

---

## Profile: Chen Ke jia Freya

### Learning Archetype
| Attribute | Value |
|-----------|-------|
| **Cognitive Style** | Highly analytical; constructs novel problem-solving methods from first principles |
| **Memorization Stance** | Actively resists rote memorization; prefers derivation and structural understanding |
| **Engagement Pattern** | Self-directed; will abandon prescribed algorithms if she identifies a more efficient logical path |
| **Risk Factor** | May overcomplicate straightforward procedures when hunting for deeper structure |

### Verified Strengths
- Decomposes multi-step problems into independent logical components without prompting.
- Frequently discovers alternative proofs or solution paths not covered in standard curriculum.
- Retains concepts permanently once the underlying mechanism is understood; flashcard-style drilling is ineffective and demotivating for her.

### Documented Conceptual Roadblocks

#### Roadblock 1: Complex Linear Regression Models
| Detail | Description |
|--------|-------------|
| **Trigger** | Multivariate regression, residual analysis, and interpreting slope coefficients in context-heavy word problems |
| **Symptom** | Freezes when presented with tabular numeric output; cannot map abstract coefficients back to the scenario |
| **Root Cause** | Linear regression is traditionally taught as a formula-first procedure (`y = mx + b`, plug-and-calculate). Freya needs to *see* the data before trusting the equation. |
| **Counter-Strategy for Scriptwriters** | **Lead with visual data plotting.** Always present the raw scatterplot *before* introducing the regression equation. Use color-coded residual bands, animated point-by-point least-squares construction, and annotated arrows tying each coefficient to a concrete visual feature of the plot. Never begin with algebraic substitution. |

#### Roadblock 2: Formulaic Notation as Black Boxes
| Detail | Description |
|--------|-------------|
| **Trigger** | Summation notation, standardized test statistics, and symbolic regression formulas |
| **Symptom** | Treats symbols as arbitrary rules to memorize; disengages |
| **Counter-Strategy for Scriptwriters** | Derive every symbol from a visual or physical intuition. Replace `Σ(xᵢ - x̄)²` with a literal animated stack of deviations. Let her "build" the formula herself on screen before it is named. |

### Scripting Directives
1. **Never** script a "step 1: write the formula" beat for Freya. Step 1 is always observation.
2. **Always** provide a visual plotting alternative for any algebraic procedure.
3. **Reward** her non-standard methods in-dialogue: e.g., "That's not the textbook route, but your logic is airtight—let's trace it."
4. **Preempt** regression anxiety by showing the plot, asking her to *predict* the line verbally, then revealing the math as a confirmation of her visual intuition.
